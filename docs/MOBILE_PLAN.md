# PrintLog למובייל — תוכנית
תוכנית להפוך את PrintLog לאפליקציית אנדרואיד (ובהמשך iOS), אחרי שגרסת הדסקטופ תסתיים. להעביר ל-Claude Code.
הגישה

* לעטוף את ממשק ה-HTML/JS הקיים עם Capacitor. רוב הקוד ב-`src/` נשאר כמו שהוא.
* צד ה-Electron (`app/main.js`, `engine.js`, `camera.js`) לא רץ בטלפון. צריך שכבה מקבילה: אותו ממשק `native.*` שה-UI כבר משתמש בו, ממומש ב-JavaScript בתוך האפליקציה + פלאגינים של Capacitor.
* מטרה: קוד אחד ל-UI, שתי שכבות native (Electron לדסקטופ, Capacitor למובייל).

שלב 1 — אנדרואיד, ענן בלבד

* התחברות לחשבון Bambu (מייל + קוד), שמירת הטוקן באחסון המאובטח של הטלפון.
* היסטוריית הדפסות מהענן, כרטיסים, סינון, הדפסות שהצליחו/נכשלו.
* סטטוס חי דרך MQTT של הענן (us.mqtt.bambulab.com) — דרך פלאגין TCP/TLS או ספריית MQTT על WebSocket אם הענן תומך.
* תצוגת תלת-ממד של המודלים (הורדת 3MF מהענן / MakerWorld) — כבר עובד ב-WebView.
* אותם headers של Bambu Studio 02.06.00.51 ואותו throttle/backoff של Cloudflare מ-`engine.js`.
* בלי ספריית קבצים מקומית בשלב הזה.

שלב 2 — אנדרואיד, רשת מקומית

* חיבור ישיר למדפסת: MQTT על TLS בפורט 8883 עם `bblp` + Access Code (צריך פלאגין socket native — דפדפן לא יכול).
* מצלמה:
   * A1/P1: תמונת תא בפורט 6000 — אפשרי עם אותו פלאגין socket.
   * P2S/X1/H2: RTSP בפורט 322 — אין go2rtc בטלפון; צריך נגן native (למשל ExoPlayer עם תמיכת RTSP) דרך פלאגין. לבדוק תמיכת H.265.
* גילוי מדפסות (SSDP) — אפשרי עם הרשאת multicast באנדרואיד.

שלב 3 — iOS

* אותו פרויקט Capacitor, בנייה ב-Xcode על המק.
* עלות: חשבון Apple Developer — 99$ לשנה — נדרש להפצה (App Store או TestFlight). בלי זה: התקנה רק על האייפון שלך, ופג אחרי 7 ימים.
* רשת מקומית: iOS מבקש הרשאת Local Network; צריך להצהיר ב-Info.plist.
* מצלמת RTSP קשה יותר (אין go2rtc); לשקול רק A1/P1 או snapshot.

הפצה

* אנדרואיד: APK חתום ישירות מ-GitHub Releases (חינם), או Google Play (25$ חד-פעמי).
* iOS: רק דרך חשבון מפתח בתשלום.
* להוסיף ל-CI job שבונה APK בכל tag.

דברים לבדוק מוקדם

* האם MQTT של ענן Bambu נגיש מטלפון בלי חסימת Cloudflare.
* תמיכת H.265 בנגן הווידאו באנדרואיד.
* גודל האפליקציה (Three.js וכו').

פיצ'ר הבא בדסקטופ — פילמנט, עלות וסטטיסטיקות
התראות לטלפון יטופלו ב-Home Assistant (בוט טלגרם), לא ב-PrintLog.
עלות בשקלים (לא מחירי Bambu)

* המשתמש מגדיר מחיר לסליל + משקל סליל, לפי סוג או מותג (למשל PLA — 80 ₪ לק"ג).
* מטבע ברירת מחדל: ₪, ניתן לשינוי.
* צריכה לכל הדפסה: גרמים מקובץ ה-3MF / נתוני הענן, מחולק לפי חריץ AMS.
* עלות חשמל אופציונלית: מחיר קוט"ש + הספק ממוצע של המדפסת × זמן ההדפסה.
* עלות מוצגת על כל כרטיס הדפסה ובמסך המודל.

גרפים וסטטיסטיקות (מסך "סטטיסטיקה")

* עלות חודשית בשקלים: פילמנט + חשמל, וכמה מזה הלך על הדפסות שנכשלו.
* צריכת פילמנט לפי סוג וצבע (גרמים לאורך זמן).
* אחוז הצלחה לאורך זמן, ולפי סוג פילמנט.
* שעות הדפסה בחודש / ניצולת המדפסת.
* מפת חום של פעילות (יום בשבוע × שעה).
* המודלים שהודפסו הכי הרבה, ההדפסות הכי יקרות והכי ארוכות.
* הפרש בין זמן משוער לזמן בפועל.
* טווח תאריכים נבחר (חודש / שנה / הכול) וסינון לפי מדפסת.

הערות מימוש

* כל החישובים מקומיים, מהיסטוריה שכבר שמורה — בלי קריאות נוספות לענן.
* גרפים ב-SVG פשוט או ספרייה קלה, תמיכה ב-RTL ובעברית/אנגלית דרך `_t`.
* הדפסות ישנות בלי נתוני משקל — מסומנות "ללא נתונים" ולא נספרות כאפס.

המלצה
להתחיל משלב 1 באנדרואיד: מהיר, חינמי, ומשתמש כמעט בכל הקוד הקיים. להחליט על שלב 2 ו-iOS אחרי שזה עובד.
