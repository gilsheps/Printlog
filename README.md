# PrintLog

ספריית מודלים להדפסת תלת-ממד (STL / 3MF) למק ולווינדוס, עם יומן הדפסות שמתמלא לבד ממדפסות Bambu Lab.

## הורדה

[הגרסה האחרונה](https://github.com/gilsheps/Printlog/releases/latest):
- **Mac (Apple Silicon, M1 ואילך):** `PrintLog-…-mac-arm64.dmg`
- **Mac (Intel):** `PrintLog-…-mac-x64.dmg`
- **Windows:** `PrintLog-…-windows-setup.exe`

ב-Mac, בפתיחה הראשונה: קליק ימני על PrintLog ← "פתח" (האפליקציה לא חתומה אצל Apple). אחרי ההתקנה הראשונה האפליקציה מתעדכנת לבד.

- תצוגת 3D ותמונות ממוזערות (כולל תמונת הפלטה של Bambu ו-צבעי פילמנט)
- תגיות, חיפוש, מועדפים, סינון לפי תיקייה ולפי מצב הדפסה
- יומן הדפסות: הצליחה / חלקית / נכשלה, עם ההגדרות מקובץ ה-3MF
- גרסאות של אותו מודל (v1, v2…)
- **סנכרון עם המדפסת**, כמו בתוסף של Home Assistant:
  - **ענן Bambu**: התחברות עם מייל + קוד, ייבוא כל היסטוריית ההדפסות ועדכון חי
  - **רשת ביתית**: חיבור ישיר למדפסת (IP + Access Code), בלי חשבון
- ארכיון ב-Google Drive, עדכון גרסה מתוך האפליקציה, התראה כשהדפסה מסתיימת או נכשלת

כל המידע נשמר בתוך תיקיית המודלים, בתיקייה המוסתרת `.shelf`. הקבצים עצמם לא זזים.
פרטי ההתחברות ל-Bambu נשמרים רק במחשב (מוצפנים במחזיק המפתחות של המערכת). הסיסמה לא נשמרת בכלל.

## התקנה

מורידים מ-[Releases](../../releases) (או מ-Actions ← הבנייה האחרונה ← Artifacts):

- **מק**: `PrintLog-…-mac-arm64.dmg` (מעבדי M) או `…-mac-x64.dmg` (אינטל).
  האפליקציה לא חתומה אצל אפל, לכן בפתיחה הראשונה: קליק ימני ← פתח.
  ב-macOS 15 ומעלה: הגדרות המערכת ← פרטיות ואבטחה ← „פתח בכל זאת”.
- **ווינדוס**: `PrintLog-…-windows-setup.exe`. אם מופיעה אזהרת SmartScreen: „מידע נוסף” ← „הפעל בכל זאת”.

## בנייה

הבנייה רצה אוטומטית ב-GitHub Actions:
- **ידנית**: Actions ← Build app ← Run workflow. הקבצים מופיעים ב-Artifacts של הריצה.
- **גרסה חדשה**: תגית בפורמט `v1.0.1` יוצרת Release עם קבצי ההתקנה.

מקומית:

```bash
npm install
npm start            # הרצה
npm run dist:mac     # בנייה למק (רק על מק)
npm run dist:win     # בנייה לווינדוס (רק על ווינדוס)
npm run build        # רק גרסת הדפדפן: dist/shelf.html
```

## מבנה

| תיקייה | מה יש בה |
|---|---|
| `src/` | הממשק (HTML/JS, three.js) – משמש גם את האפליקציה וגם את גרסת הדפדפן |
| `app/` | האפליקציה (Electron): חלון, מגש, הרשאות קבצים, מנוע הסנכרון (`engine.js`) |
| `helper/shelf_sync.py` | תוכנת סנכרון עצמאית (Python) לגרסת הדפדפן |
| `.github/workflows/` | בנייה אוטומטית למק ולווינדוס |

## הערה על Bambu

החיבור לענן משתמש באותו ממשק לא רשמי שבו משתמשים Bambu Studio, Bambu Handy ו-[ha-bambulab](https://github.com/greghesp/ha-bambulab). Bambu יכולה לשנות אותו. החיבור ברשת הביתית לא תלוי בו.
