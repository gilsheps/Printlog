# PrintLog: הורדות

כאן מתפרסמות הגרסאות של **PrintLog**, ספריית קבצי ההדפסה עם היסטוריית ההדפסות מ-Bambu Lab.

**להורדה:** [הגרסה האחרונה](../../releases/latest)

- **Mac (Apple Silicon, M1 ואילך):** `PrintLog-…-mac-arm64.dmg`
- **Mac (Intel):** `PrintLog-…-mac-x64.dmg`
- **Windows:** `PrintLog-…-windows-setup.exe`

אחרי ההתקנה הראשונה, האפליקציה מודיעה כשיש גרסה חדשה ומתעדכנת לבד ("עדכן עכשיו").

> ב-Mac, בפתיחה הראשונה: קליק ימני על PrintLog ← "פתח" (האפליקציה לא חתומה אצל Apple).
